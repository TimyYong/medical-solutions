## 👋 关于本仓库

我从事**医疗信息化**相关工作。这里用来沉淀工作中的解决方案、技术选型思考与实践经验——不一定有代码，但每一份方案都是真实场景下的总结。

**内容说明**：所有内容均为脱敏后的通用描述，不包含任何客户信息、真实业务数据或内部系统细节。

## 📝 方案模板

想新增一份方案？先看看 **[方案写作模板](TEMPLATE.md)**，里面给出了统一的结构（背景痛点 → 建设目标 → 整体架构 → 核心能力 → 实施路径 → 效果价值），照着填就行。

## 🔧 如何使用这个仓库

- **看方案**：点上面的目录链接，或直接点开某个 `.md` 文件
- **加方案**：复制 `TEMPLATE.md`，按结构填写内容，放到对应目录下
- **看历史**：点文件页面的 "History" 可以看到每次修改记录
- **分享**：每个文件都有永久链接，可以直接发给同事或朋友
