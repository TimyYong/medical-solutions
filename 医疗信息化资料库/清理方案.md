# 清理方案（待确认，尚未执行任何移动）

> ⚠️ **此方案涉及移动 **`D:\办公文件`** 中的文件。在你明确确认前，我不动任何文件。**
> 执行方式是「移动」而非「删除」：所有文件移到 `_清理隔离区\`，保留原相对路径，台账可一键还原。

## 一、可安全清理（建议执行）

### 1. 系统垃圾文件 —— 4248 个 / 16.2 MB

| 类型 | 数量 | 说明 |
| --- | --- | --- |
| AppleDouble `._数值` `._表格` `._数据.json` | 4144 | macOS 在 D 盘写入的资源分叉，Windows 下完全无用 |
| Word 临时锁文件 `~$*.docx/.pptx/.xlsx` | 69 | 异常退出残留，打开文档时会报「文件被占用」 |
| `.DS_Store` | 17 | macOS 目录图标缓存 |
| `.WeDrive` | 15 | 企业微信盘同步残留 |
| `Thumbs.db` / `desktop.ini` | 3 | Windows 缩略图缓存 |

零信息量，移出后不影响任何文档打开。

### 2. 同目录内的多余副本 —— 33 个 / 27.9 MB

同一文件夹里 `xx.pdf` 和 `xx(1).pdf` 并存这类误复制（内容指纹完全相同）。
保留不带 `(1)/副本/copy` 后缀的那份，其余移出。

样例：

- `奇点文件\项目文件\芜湖全民健康信息平台\…（定）(1).pptx`（同目录已有 `…（定）.pptx`）
- `306文件\建设方案 (1).doc`
- `306文件\云化大数据项目软件功能需求调研计划20241107(1).docx`

## 二、不建议动（只出清单）

### 跨目录重复 —— 291 份 / 373 MB

同一份文件在不同项目目录各存一份，例如《芜湖市全民健康信息平台汇报PPT》同时出现在
`奇点文件\项目文件\芜湖全民健康信息平台\` 和 `奇点文件\张炜-生命奇点文档\…\芜湖\可行性报告\`。

**这类不是误复制，是各项目目录的自包含。** 删掉会让某个目录不再自成一体，取用时要跨目录找。
建议保留原状，清单见 `重复文件清单.csv`。

## 三、执行方式

```bash
cd _build

# 演练（默认，不动文件）
python cleanup_move.py --kind junk
python cleanup_move.py --kind dupsame

# 执行
python cleanup_move.py --kind junk    --apply
python cleanup_move.py --kind dupsame --apply

# 后悔药：按台账一键还原
python cleanup_move.py --restore "_清理隔离区\台账_junk_<时间戳>.csv"
```

- 隔离区：`D:\WORKBUDDY 2\2026-11-16-12-09-44\_清理隔离区\`
- 每次执行生成台账 CSV（原路径 / 字节 / 隔离区路径 / 状态），可逐条核对
- 移动后资料库索引不会失效（索引存的是相对路径，文件仍在原相对位置之外但在隔离区同构目录下）

## 四、移动后的影响

- `D:\办公文件` 中不再有 `._*`、`.DS_Store`、`~$*` 这类条目，资源管理器里更干净
- 下次全量扫描的文件数会从 16481 降到约 12200（不再重复统计垃圾）
- 隔离区占 44 MB，你确认无用后可整个目录删掉，腾出空间

## 五、需要你确认的三件事

1. 是否执行？范围选哪个（仅垃圾 / 垃圾+同目录重复 / 全部）
2. 保留规则是否认可（不保留带「副本/拷贝/copy/(1)」后缀、路径更短、修改时间更早）
3. 是否需要我在移动前先做一次完整备份（`robocopy` 复制到隔离区前的快照目录）
